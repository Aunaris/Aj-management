2D Animation Classroom — โปรแกรมเช็คชื่อ ส่งงาน และให้คะแนนระหว่างคาบ
================================================================

วิธีเปิดโปรแกรม
  Windows : ดับเบิลคลิก "Start.bat"
  macOS   : คลิกขวาที่ "Start.command" > Open (ครั้งแรกเท่านั้น) จากนั้นดับเบิลคลิกได้ตามปกติ

โปรแกรมจะเปิดหน้าต่างสีดำ (ห้ามปิดระหว่างใช้งาน) และเปิดเว็บเบราว์เซอร์ให้อัตโนมัติ
ถ้าเบราว์เซอร์ไม่เปิดเอง ให้เข้า http://localhost:3000

บัญชีเริ่มต้น (ระบบจะให้เปลี่ยนรหัสผ่านเมื่อเข้าครั้งแรก)
  อาจารย์ : aunalyst / teacher1234   หรือ   piriya / teacher1234
  Admin  : admin / admin1234
  นักศึกษา : รหัสนักศึกษา / รหัสนักศึกษา (หลังนำเข้ารายชื่อ)

เริ่มต้นใช้งาน
  1. เข้าเป็นอาจารย์ > เมนู "นักศึกษา" > อัปโหลดไฟล์ ClassRoster ทั้ง 3 ไฟล์
  2. เมนู "กลุ่มเรียน (Section)" > ตรวจวันเปิดภาค แล้วกด "บันทึกและคำนวณวันเรียนทุกกลุ่ม"
  3. เมนู "ตั้งค่ารายวิชา" > ตรวจและยืนยันโครงสร้างคะแนน

ให้นักศึกษาสแกน QR ด้วยมือถือ
  - PC เครื่องนี้และมือถือนักศึกษาต้องต่อ Wi-Fi/เครือข่ายเดียวกัน
  - หน้าต่างสีดำจะแสดงที่อยู่สำหรับนักศึกษา เช่น http://192.168.1.25:3000 (QR ใช้ที่อยู่นี้ให้อัตโนมัติ)
  - Windows: ครั้งแรกจะมีหน้าต่าง Windows Firewall ถาม ให้กด "Allow access" (เครือข่าย Private)
  - Wi-Fi บางแห่งของมหาวิทยาลัยกันไม่ให้อุปกรณ์มองเห็นกัน (client isolation) ถ้าสแกนแล้วเปิดไม่ได้
    ให้ใช้ Hotspot หรือ Router ของห้อง หรือติดตั้งบนเซิร์ฟเวอร์
  - การตรวจ GPS ต้องใช้ HTTPS จึงใช้ไม่ได้ในโหมดนี้ (ให้ปิดไว้) — การที่นักศึกษาต้องอยู่ใน Wi-Fi
    เดียวกับเครื่องอาจารย์ก็ช่วยยืนยันว่าอยู่ในห้องเรียนแล้ว และยังใช้ "1 เครื่อง 1 คนต่อคาบ"
    กับ "สุ่มรหัสยืนยันในห้อง" ได้ตามปกติ

ข้อมูลของระบบ
  - ทุกอย่างเก็บในโฟลเดอร์ "data" ข้างไฟล์นี้ (ฐานข้อมูล ไฟล์งานที่นักศึกษาส่ง กุญแจเข้ารหัส)
  - สำรองข้อมูล: ปิดโปรแกรม แล้วคัดลอกโฟลเดอร์ "data" ทั้งโฟลเดอร์เก็บไว้
  - ย้ายเครื่อง: คัดลอกทั้งโฟลเดอร์โปรแกรม (รวม data) ไปเครื่องใหม่
  - อัปเดตโปรแกรมรุ่นใหม่: แตกไฟล์รุ่นใหม่ แล้วคัดลอกโฟลเดอร์ "data" เดิมมาวางแทน
  - ข้อมูลมีรายชื่อนักศึกษา (ข้อมูลส่วนบุคคล) ควรตั้งรหัสผ่านเครื่อง และไม่แชร์โฟลเดอร์ data

ข้อควรรู้
  - นักศึกษาส่งงาน/ดูคะแนนได้เฉพาะตอนที่ PC เครื่องนี้เปิดโปรแกรมอยู่ และอยู่ในเครือข่ายเดียวกัน
    ถ้าต้องการให้ส่งงานจากบ้านได้ตลอดเวลา ต้องติดตั้งบนเซิร์ฟเวอร์ที่มี HTTPS
  - การรับงานทางอีเมลทำงานเมื่อโปรแกรมเปิดอยู่ (ดึงอีเมลย้อนหลังที่ค้างไว้ให้เมื่อเปิดครั้งถัดไป)
